# QAFAROVS — Creative Digital Studio

A responsive portfolio site for QAFAROVS, an independent creative practice focused on websites, digital products, visual identity, and communications.

The site is built with plain HTML, CSS, and JavaScript. There is no build step.

## Run locally

From the repository root, start a static server:

```powershell
py -m http.server 8000 --directory dist
```

Then open http://localhost:8000.

## Pages

Home, Services, Work, Journal, About, Contact, and project detail pages live in `dist/` with their assets in `dist/assets/`.
